# 与未重构版（Python）的对照

重构前的实现在 `E:\workspace\salary_app`（Flask + Tkinter + pystray），
本文逐项对照两版的能力，说明**哪些一致、哪些是重构后更强、哪些补了回来**。

对照基准是原版仓库里的这些文件：

| 原版文件 | 作用 |
| --- | --- |
| `app.py` | Web 服务（Flask）、认证、CSRF、会话、审计 |
| `excel_data.py` | 员工表/工资表解析、登录校验、动态字段发现 |
| `cache.py` | 按 mtime 失效的数据缓存 |
| `control_panel_pkg/ui.py` | Tkinter 控制面板（59 KB，两个标签页） |
| `control_panel_pkg/service.py` | 服务启停、**看门狗保活**、自签证书 |
| `control_panel_pkg/field_config.py` | 字段三态配置读写 |
| `control_panel_pkg/tray.py` | 托盘图标与菜单 |
| `app_icon.ico` | 应用图标（6 种尺寸） |
| `使用说明书.md` | 面向用户的使用说明 |
| `tests/` | 11 个 pytest 文件 |

---

## 一、总体结论

- **业务能力没有丢**：登录、查工资、字段三态、端口、开机自启、防火墙、
  打印/导出、审计这些都在。
- **重构后更强的地方**：性能（见 [PERFORMANCE.md](PERFORMANCE.md)）、
  单文件分发、无 Python 依赖、界面按《设计风格规范.md》重做、
  窗口可缩放、图标统一、测试从 11 个 pytest 文件变成 77 个 Rust 用例。
- **补回来的原版能力**：**看门狗保活**、**登录提示**、**退出确认**、**HTTPS 地址**、
  **统一图标**（这五项是本轮对照后补上的）。
- **有意去掉的**：管理员角色与管理员接口（早前按需求移除）、
  HTTP→HTTPS 强制跳转（两个端口都直接服务，更方便）、
  CSRF（改用无 Cookie 的令牌认证，没有 CSRF 面）。

## 三、本轮补齐的五项

### 1. 看门狗保活（最要紧）

原版 `service.py` 有一整套保活：监控 HTTP/HTTPS 线程、`/healthz` 探活检测死锁、
自动重启、十分钟窗口内计数、超过上限停止重启。

Rust 版的服务跑在托盘进程内（独立 actix 运行时），**运行时一旦崩掉就没人再起来**——
员工会直接查不了工资，而面板还显示「已停止」，没人知道该做什么。

本轮补上（`tray/src/service.rs`）：

- 判据：用户开着服务、运行时已经不在、端口也没人在听 → 判定为掉线；
- 自动拉起，10 分钟窗口内计数，超过 5 次停止自动重启并提示运维；
- 面板上显示「异常退出后已自动恢复 N 次」，恢复时给一条通知。

### 2. 登录提示

原版面板上有醒目的一行：**账号 = 工号，密码 = 紧急联系人号码**。
这是员工能不能登录的关键信息，Rust 版面板上没有（网页登录页有说明，但运维看不到）。
本轮加在访问地址卡片里，端口行右侧。

### 3. 退出确认

原版退出托盘时，若服务在跑会弹确认框（服务运行中退出 = 全员查不了）。
Rust 版之前是直接停服务退出。本轮补上确认框。

### 4. HTTPS 访问地址

Rust 版一直在 5002 提供 HTTPS，但面板上只有 HTTP 地址，运维不知道 HTTPS 也在。
本轮在访问地址卡片里补上 HTTPS 一行（与原版一样分 HTTP / HTTPS 两行）。

### 5. 图标统一

原版自己就不统一：托盘图标是 PIL 现画的蓝色圆圈，EXE 图标是 ico 里的蓝色圆角方块。

本轮把原版的 `app_icon.ico` 作为 Windows 资源内嵌进 exe
（`scripts/sync_app_icon.py` 负责同步），四处统一用这一张：

- 标题栏 / 任务栏：从资源 `LoadImage`；
- 托盘：取系统解码好的图标像素转 RGBA；
- 侧边栏 logo：同一份像素按主题底色预合成后贴图。

> 图标的 PNG 解码交给系统（`GetIconInfo` + `GetDIBits`），
> 不在 Rust 里另写一套 PNG 解码器。

原版面板的「支持访问的网络」是硬编码的公司网络（办公区域网络 / JTOFFICEWIFI / 宿舍网络），
现在改成读 `data/networks.txt`：

```
有线 | 办公区域网络 | yes
WiFi | JTOFFICEWIFI、JTOFFICEWIFI_2.4G | yes
宿舍网络 | 暂不支持访问 | no
```

换办公地点只要改这个文件，不用改代码重编。

## 五、兼容性

- **`data/fields.txt`**：两版格式互相兼容（`show/hide/auto` 与 `显示/隐藏/跟随` 都能读）。
  原版写的文件，Rust 版读得懂；反过来也一样。
- **员工表**：列识别关键字表（`ID_KEYWORDS` / `PASSWORD_KEYWORDS` / …）与原版一致，
  原版能登录的员工，Rust 版也能登录。
- **工资表**：按「文件名里的年月」匹配，规则一致（`2026 年 10 月员工工资.xlsx`）。
- **数据目录**：文件名与布局一致（`data/员工列表.xlsx`、`data/salary/`、`data/fields.txt`、
  `data/port.txt`、`data/certs/`、`data/audit.log`），老数据直接可用。
